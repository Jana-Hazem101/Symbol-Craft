<h3>The Project</h3>
<p>
  Pixel Name Art is a C-based console application. 
</p>
<ul>
  <li><b>Choose a symbol:</b> Like <code>*</code>, <code>#</code>, or <code>@</code>.</li>
  <li><b>Enter a name:</b> To see it transformed.</li>
  <li><b>Select size:</b> Pick a scale from 1 to 5.</li>
</ul>
