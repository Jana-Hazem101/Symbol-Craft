<h1 align="center">Symbol Cr🅰️ft</h1>

<p align="center">
  <strong>"Turn any name into art!"</strong><br>
  This project is my first step into <b>Computer Graphics</b> using C. <br>
  I built it to understand how characters are represented as pixels and grids.
</p>

<hr>

<h3>♡ Project Overview</h3>
<p>
  Pixel Name Art is a C-based console application. 
</p>
<ul>
  <li><b>Choose a symbol:</b> Like <code>*</code>, <code>#</code>, or <code>@</code>.</li>
  <li><b>Enter a name:</b> To see it transformed.</li>
  <li><b>Select size:</b> Pick a scale from 1 to 5.</li>
</ul>
